# Mãos que Acolhem — Projeto Acadêmico

Projeto acadêmico de desenvolvimento front-end com HTML, CSS e JavaScript.

## Estrutura
- `html/` — páginas do projeto
- `css/` — estilos
- `js/` — comportamentos e máscaras do formulário
- `imagens/` — recursos gráficos
- `.vscode/` — configuração opcional do VS Code

## Validação do formulário
O cadastro utiliza validação nativa do HTML (`required`, tipos de campo e restrições) e JavaScript para máscaras de CPF, telefone e CEP.


## Componentes de feedback

A página inicial inclui a demonstração acadêmica de quatro componentes: **Badges + Alertas**, **Toast aberto**, **Modal aberto** e **versão responsiva/mobile**.

- Badges para indicar status e categorias;
- alerta visual para orientar o usuário;
- toast temporário acionado por botão;
- modal com abertura, fechamento por botão, clique externo e tecla Esc;
- adaptação dos componentes para telas menores.
